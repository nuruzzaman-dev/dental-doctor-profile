# Supplied Webflow Reference Audit

## ProliDent
The live page uses a direct clinic-first structure: a simple top navigation, a split hero with a large black sans-serif headline and a real doctor/patient image, two clear CTAs, and a floating contact-information band immediately below the hero. The page creates momentum through strong section blocks rather than small cards. Contact, clinic hours, emergency availability, and address are treated as primary trust content. Services are presented as a broad visual catalogue, with multiple image-led entries and clear “learn more” paths. The page also uses decorative shape graphics and a blue/green clinic palette instead of a muted editorial paper palette.

## EcoDentistry
The reference uses a light gray/white base with a bright sky-blue accent, large heavy sans-serif headlines, rounded organic graphic shapes, and a more modern health-brand tone. The hero is compact, visual, and CTA-forward. The next section combines a large image, benefits, and a secondary contact action. Service content is organized as a visual spectrum rather than a dense information grid. Metrics, reasons to choose the clinic, an appointment CTA, and testimonials create a clear conversion funnel. The overall rhythm is more energetic, less literary, and more product-like than the current page.

## Dentello
The supplied URL currently returns a 404 page, so no reliable visual evidence was available from this reference. It should not be treated as a design source until a working URL is provided.

## Direction extracted for the refactor
The redesign should move away from the current warm ivory / brass / repeated card system. The stronger shared cues are: a confident high-contrast sans-serif display type, a fresh mint–teal–deep navy palette, full-width color fields, asymmetrical but practical split sections, real clinic and doctor imagery, rounded organic shapes used sparingly, a hero that communicates clinic value immediately, and contact details placed early rather than hidden near the bottom. The new page should feel like a modern healthcare brand website: clear, energetic, credible, and visually memorable.

The new structure will prioritize a bold hero, an early trust/contact strip, a large doctor story section, an open service index with image hover movement instead of boxed cards, a visual care journey, a credibility/metrics band without fabricated reviews, and a strong final booking section. Mobile should collapse into short, fast sections with the booking CTA always reachable.
